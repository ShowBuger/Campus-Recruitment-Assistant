欢迎使用校招信息看板
几分钟了解主要功能与推荐使用顺序

    

      
从个人总表开始
先维护岗位信息，再加入投递流程。所有账号数据独立保存在云端。

      

        
01
维护岗位
在“总表信息”中新建、导入或从共享总表添加岗位；点击公司名称可打开完整详情。

        
02
跟踪投递
把岗位加入投递后，可在投递信息和投递看板中维护进展、时间节点与结果。

        
03
日历提醒
校招日历会汇总投递、机考、面试和截止时间，也可以添加自定义日程。

        
04
使用 AI
先在右上角 AI 配置中保存自己的 API Key，再从岗位详情使用 AI 补全，或进入简历分析。

        
05
共享与聊天
共享总表可供所有用户查找岗位；右上角聊天支持消息、图片和岗位转发。

        
06
手机使用
表格区域可横向滑动，弹窗内可纵向滚动；常用操作会自动适配窄屏。

      

      
提示AI Key 仅保存在你的独立配置中。重要岗位信息与截止时间仍建议打开官方入口核对。

浏览器扩展

              
推荐使用浏览器扩展进行自动填充，支持所有页面（含 SPA）

            


            

              
安装步骤

              

                
1. 下载扩展文件：📦 下载 extension.zip

                
2. 打开 Chrome，地址栏输入 chrome://extensions

                
3. 打开右上角「开发者模式」

                
4. 将下载的 extension.zip 解压

                
5. 点击「加载已解压的扩展程序」，选择解压后的文件夹

                
6. 点击扩展图标，填写服务器地址和令牌即可使用

              

            


            

              
登录凭据

              

                
使用与看板相同的用户名和密码登录

                
点击扩展图标后输入凭据，登录成功后可选择模板和填充模式

              

            


            

              
使用说明

              

                
• 登录后扩展每 5 分钟自动检查更新

                
• 打开任意校招投递页面，扩展会自动检测表单（右上角弹窗）

                
• 点击扩展图标可手动选择模板和填充模式

                
• 支持 全量填充、增量填充（仅填空字段）、AI 匹配

                
• 模板在此页面管理，扩展自动同步
