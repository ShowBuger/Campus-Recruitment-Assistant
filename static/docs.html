使用流程

  1. 注册账号 — 联系管理员获取邀请码完成注册
  2. 添加岗位 — 在「总表信息」中手动新建，或从共享总表中一键复制
  3. 跟踪进展 — 将岗位状态改为"已投递"后，在看板和日历中维护后续进展
  4. 配置邮箱（可选）— 在「进度跟踪」面板绑定邮箱，自动从邮件识别投递状态
  5. 使用 AI（可选）— 在右上角 AI 配置中填写 API Key，解锁公司补全和简历分析

岗位管理

新建岗位

点击「新建记录」按钮，填写公司名称、岗位名称、城市、批次等基本信息。建议同时填写投递链接和岗位 JD，方便后续 AI 分析使用。

进展字段

每个岗位的「进展」字段支持多选，可选值包括：未投递、已投递、机考、面试、OC、Offer、已挂。系统会根据进展自动归类到看板对应区域。

字段说明

  • 公司/行业类型 — 用于看板分类统计，如"互联网""芯片/半导体""车企"
  • 嵌入式方向 — 多选，如"Linux驱动""RTOS""AI芯片"
  • 投递链接 — 岗位入口 URL，共享岗位必须填写此项
  • 时间字段 — 投递时间、机考时间、面试时间、保温等均为毫秒时间戳，日历自动解析

导入导出

支持 Excel (.xlsx) 批量导入导出。导入时会自动根据公司+岗位去重，已存在的记录不会被覆盖。

邮箱进度跟踪

功能概述

系统通过 IMAP 协议连接你的邮箱，拉取最近邮件并用本地关键词规则自动判断每封邮件对应的招聘阶段，支持识别以下五种进展：

已投递 机考 面试 OC 已挂

配置步骤

  1. 登录你的邮箱网页版，进入「设置 → POP3/SMTP/IMAP」
  2. 开启 IMAP 服务，获取客户端授权码（非邮箱登录密码）
  3. 在看板「进度跟踪」面板填写邮箱地址、授权码和 IMAP 服务器地址
  4. 点击「测试连接」预览最近 10 封邮件的识别结果
  5. 确认无误后，将模式切换为「自动确认」并启用自动跟踪

QQ 邮箱详细配置教程

  1. 浏览器登录 QQ邮箱网页版 → 右上角齿轮图标 → 设置 → 账户 → 安全
  2. 向下滚动找到 「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
  3. 点击 「IMAP/SMTP服务」 → 「开启」
  4. 按提示使用绑定的密保手机发送指定短信到指定号码，发送后点击「我已发送」
  5. 页面将显示一个16 位授权码（字母+数字），立即复制保存——只显示一次
配置项填写内容
接收邮件服务器imap.qq.com
接收端口993（加密方式 SSL/TLS）
用户名完整 QQ 邮箱地址
密码16 位授权码（非 QQ 登录密码）
发送短信前需确保 QQ 邮箱已绑定手机号。授权码遗失后需在设置中重新生成（旧码自动失效）。

163 邮箱详细配置教程

  1. 浏览器登录 163邮箱网页版 → 右上角齿轮图标 → POP3/SMTP/IMAP
  2. 在「IMAP/SMTP服务」旁点击 「开启」，弹出安全提示后点击「继续开启」
  3. 使用手机扫描二维码发送短信验证，发送成功后点击「我已发送」
  4. 系统生成客户端授权码，立即复制保存——仅显示一次，关闭页面后无法再次查看
配置项填写内容
接收邮件服务器imap.163.com
接收端口993（加密方式 SSL/TLS）
用户名完整 163 邮箱地址
密码客户端授权码（非邮箱登录密码）
163 邮箱授权码有效期为 180 天，到期后需重新获取。免费账户最多同时保留 2 个授权码。

识别置信度层级

AUTO · 97% REVIEW_HIGH · 88% REVIEW_LOW · 68% IGNORE · 跳过

AUTO 级别的识别结果（关键词明确 + 公司/岗位匹配成功）可在「自动确认」模式下直接更新岗位进展，无需手动确认。

本地关键词规则

系统按优先级扫描邮件主题和正文中的关键词，匹配逻辑如下：

阶段正向关键词（命中即匹配）负向关键词（命中排除）
已投递投递成功、网申成功、申请已提交、简历已收到、感谢您投递—
机考笔试邀请、测评邀请、AI测评、在线测评、机考通知测评已过期、测评完成
面试面试邀请、面试通知、确认面试时间、一面/二面/三面、复试通知面试结果将在之后、面试未通过
OC录用通知、录取通知、意向书、入职邀请、offer letter—
已挂很遗憾、未能通过、未通过、岗位已关闭、流程终止—
测试同步不会修改任何岗位数据，仅预览识别结果。确认邮件识别正确后，再开启自动跟踪。

AI 增强识别

在进度跟踪配置中开启「AI 自动识别」后，系统将使用大模型逐批分析邮件，判断逻辑更接近 SKILL.md 中的完整 SOP。AI 不可用时自动降级为本地关键词识别。

AI 功能

配置 AI 服务商

在右上角齿轮图标进入「AI 配置」，支持 DeepSeek、OpenAI、Claude、Kimi 四种服务商。填写 API Key 后即可使用以下功能：

  • 公司信息补全 — 在岗位详情中点击「AI 补全」，自动查询公司业务、行业类型和嵌入式方向
  • 简历分析 — 上传简历后，选择匹配、技术面、HR 面、简历优化等分析模式

简历分析模式

  • 综合匹配分析 — 简历与 JD 的匹配度评估、优势、缺口和改进建议
  • 技术面试训练 — 生成 10 道针对性技术面试题及参考回答
  • HR 面试训练 — 8 道校招 HR 面专项问题
  • 完整面试流程 — 模拟四面完整流程（一面到 HR 面）
  • 简历定向优化 — 逐段诊断并提供修改建议

日历与提醒

校招日历

日历视图自动汇总所有岗位的投递截止、机考、面试等时间节点。点击日历中的事件可跳转对应岗位详情。

自定义日程

在日历面板中可以添加个人日程（如宣讲会、面试备忘），支持日期和标签。

提醒

系统会根据投递截止时间和面试时间在通知栏显示即将到来的重要事件。

共享与聊天

共享总表

将个人岗位共享到「共享总表」后，其他用户可以看到并一键复制到自己的总表中。共享岗位包含公司、岗位、方向、城市、链接等基本信息。

即时聊天

右上角聊天功能支持文本消息、图片和岗位转发。转发岗位时，接收方可以直接复制到自己的总表。

常见问题

Q: 授权码和邮箱密码有什么区别？

授权码是邮箱服务商为第三方客户端生成的专用密码，与登录密码不同。使用授权码可以避免暴露主密码，也更安全。在邮箱设置的「POP3/SMTP/IMAP」中可以生成。

Q: AI 补全和简历分析需要付费吗？

系统本身免费，但使用 AI 功能需要你自己向服务商（如 DeepSeek、OpenAI）购买 API 额度。建议先用便宜的模型（如 DeepSeek V4 Flash）测试。

Q: 邮箱跟踪会读取所有邮件吗？

系统只读取收件箱中最近 20 封未读邮件（按 UID 增量），且仅缓存主题、发件人和正文摘要用于本地关键词匹配。邮件内容不会上传到任何第三方服务。
